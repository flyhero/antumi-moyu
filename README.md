# antumi-moyu

两个 [Antumi](https://github.com/flyhero/antumi) 插件：在 Antumi 里看 linux.do 或 V2EX 的帖子，界面和 AI 聊天页一样。两个社区各是一个插件，只装自己要的那个，也可以都装。

- 话题列表是「会话」，楼主的帖子是你发的消息，每一楼回复是助手的回答。
- 配色、字体跟着 Antumi 当前的主题走。
- 可以匿名阅读；登录后可读取账号可见的内容，并在插件里回复帖子。

## 安装

需要支持插件页面的 Antumi（插件 `manifest.json` 的 `engines.antumi` 写着最低版本）。登录和回复还需要包含「插件浏览器会话」能力的新版宿主；旧宿主仍可匿名阅读，登录时会提示升级。

| 社区 | 附件名 | 侧栏入口 |
|---|---|---|
| linux.do | `antumi-moyu-linuxdo.zip` | 阅读 L |
| V2EX | `antumi-moyu-v2ex.zip` | 阅读 V |

支持自定义插件图标的新版 Antumi 会分别显示 L 和 V 形状的侧栏图标；旧宿主沿用通用插件图标。

在 Antumi 里打开「设置 → 插件 → 从其他位置安装」：

- **GitHub Release**：仓库填 `flyhero/antumi-moyu`，「ZIP 附件名」填上表里的名字。两个都要就装两次。以后在同一页点「检查并更新」就能升级。
- **本地文件**：从 [Releases](https://github.com/flyhero/antumi-moyu/releases) 下载对应的 ZIP 后选择它。这样装的不会自动找到新版本。

## 用法

点左侧话题打开帖子，在列表顶部选择频道。输入框专门用于回复；未登录时仍可匿名阅读。

帖子右上角提供楼层跳转（`#` 图标）、刷新、在内置浏览器打开和回到会话按钮。底部「加载更多回复」继续读取下一页。切换帖子或重开插件后，再打开同一帖子会恢复之前的楼层和楼层内位置；需要回看时可点「加载前面的回复」。阅读位置按社区、账号和帖子分别保留。

不在输入框里时可用快捷键：`j` / `k` 切到下一个 / 上一个话题，`n` 加载下一页，`r` 刷新列表和当前帖子，`o` 在浏览器打开，`q` 回到会话。连按两次 Esc 也能离开。回复框中输入这些字符会照常写进草稿。

输入框下方有三个图标开关，依次是流式输出、图片显示、头像伪装；悬停显示名称和当前状态，开关偏好会保存。流式输出让回复逐条显示，关闭时直接展示全部已加载内容。

帖子列表缓存 3 分钟，到期后自动刷新一次；页面隐藏时等回到页面再刷新。成功后重新计时，失败时保留列表并显示错误，等你手动重试。帖子正文不会自动刷新，可用 `r` 更新。

列表顶部、频道名称左侧的刷新图标只更新帖子列表，不会重新加载正在读的帖子；请求期间图标转动，暂时不能重复点击。

## 登录与回复

点击帖子上方的「登录」，在 Antumi 内置浏览器的社区官网完成登录和验证码，然后回到插件点击「检查登录状态」。出现用户名并打开帖子后，即可在输入框写回复；回车或点击「发送回复」发布，Win + 回车换行（macOS 使用 ⌘ + 回车），输入法选字时回车不会发送。成功后读取新回复所在页并定位到该楼层，进入审核队列时保留当前阅读位置并写明等待审核。

每条评论下方的回复图标可指定回复对象，输入框上方会显示用户名和楼层；点叉号取消指定，正文保持不变。linux.do 使用社区原生的楼层回复关系；V2EX 会在正文前加上 `@用户名 #楼层`，沿用社区的文本回复方式。切换帖子时，正文和回复对象按社区、账号和帖子分别保留。

登录状态按 Antumi 数据目录、插件和站点隔离，由宿主的浏览器会话保存；页面和页面持久状态都不保存 Cookie。点击「退出登录」会关闭该插件的登录标签并清理对应会话，其他插件和普通浏览器的账号不受影响。登录账号变化时清掉阅读缓存。

正文和回复对象自动保存到 Antumi 本地的插件页面状态，关闭页面后再打开可继续，发送成功或提交审核后清除该条草稿。发送期间禁用重复点击。登录失效提供「重新登录」，限流时显示等待提示，社区给出等待时长时会暂时禁用发送。超时、响应不明确或发送途中关闭页面时，草稿会保留结果待确认的标记；可先点「查看帖子」，确认没有发出后再点「确认未发出，允许重发」。任何失败都不会自动重发。

插件页面存储上限为 32 KiB，设置、草稿和阅读位置共用。空间紧张时先淘汰旧阅读记录，不会截断或自动删除草稿；仍放不下或存储不可用时，会明确提示草稿暂未保存，当前页面内的正文保持完整。

输入框下方的面具图标是「头像伪装」，与「流式输出」「图片」并列，悬停显示名称和开关状态，可将回复者头像换成 Antumi 的 Agent 标志，默认关闭。按社区和昵称稳定分配，同一用户在不同帖子里保持一致，开关状态会保存；真实昵称和引用关系照常显示。标志随插件打包，开启后不请求原头像。

## 我的通知

登录后，页头的铃铛显示官网未读数量，点击查看通知列表；支持手动刷新和「加载更多通知」。linux.do 通过社区实时通知通道更新角标和已打开的列表；V2EX 每 3 分钟以及回到页面时检查未读数。打开通知列表时读取最新内容。

点击通知可在插件中打开对应帖子和楼层，当前回复草稿保留。勋章等非帖子通知会在内置浏览器打开官网页面；回复链接没有足够的楼层定位信息时也使用官网原链接。

- **linux.do**：未读通知会突出显示，点右侧勾号可单独标记已读，确认成功后再更新列表和角标。打开列表或点击帖子不会自动把通知标为已读。
- **V2EX**：沿用官网规则，查看通知列表后会清除未读计数，列表上也会说明；不提供逐条标记。

通知只在当前页面内存中保留，不写入页面持久状态。退出或切换账号时清空列表，旧账号尚未结束的请求不会覆盖新账号的通知；请求失败可手动重试。

## 限制

- **linux.do 限流很紧。** 十几秒内连着点几个帖子就可能被拦，页面会提示过一会儿再试。除当前可见列表缓存到期后的刷新外，插件只在你操作时请求，不在后台刷新或自动重试。
- **代理**：匿名阅读跟着系统的 HTTPS 代理走（macOS 和 Windows 的系统代理设置）；设了 `HTTPS_PROXY`、`ALL_PROXY` 或 `HTTP_PROXY` 环境变量时以环境变量为准，`NO_PROXY` 和系统的例外列表里的地址直连。匿名请求只支持 HTTP 代理，系统里只配了 SOCKS 或 PAC 脚本时按直连处理，Linux 只读环境变量。登录后的请求使用 Antumi 内置浏览器的代理设置。
- **图片默认折叠**，点开才加载；图片所在的站点能看到你的 IP，和用浏览器看帖一样。论坛自己的表情直接显示。
- 匿名阅读受社区公开范围限制；登录后仍受账号自身权限限制。V2EX 匿名接口一次取回全部回复，登录后使用网页会话分页读取。

## 开发

```sh
npm ci
npm run check     # 类型检查、测试、构建 dist/antumi-moyu-linuxdo.zip 和 dist/antumi-moyu-v2ex.zip
npm run preview   # http://127.0.0.1:4173 ，用假数据在浏览器里看页面；加 ?only=v2ex 看单个社区的样子
```

`src/` 是两个插件共用的后台，`page/` 是共用的页面，`plugins/<社区>/` 是每个插件自己的清单和入口，约定见 [AGENTS.md](AGENTS.md)。接口和限制见 Antumi 的 [插件文档](https://github.com/flyhero/antumi/blob/main/docs/PLUGINS.md)。

发布：`package.json` 和两个 `plugins/*/manifest.json` 改成同一个版本号，推送标签 `v<版本号>`，Release 工作流会构建并把两个 ZIP 附在同一个 Release 上。ZIP 的名字不带版本号，Antumi 靠这个名字在最新的 Release 里找到更新。
